MM-Companion now runs on Linux — including the Steam Deck — with a download that
needs no Python, plus a fix for homebrew power overrides that showed one number and
rolled another.

## Changes

- **Linux release.** Every release now comes with a Linux download beside the
  Windows installer. Extract it and run `./install.sh`: it installs just for you (no
  root needed), adds MM-Companion to your applications menu with its icon, and
  upgrades or removes it again the same way. Your characters, mods and settings live
  in `~/.local/share/MM-Companion` and are never touched by an upgrade. You can also
  run it straight from the extracted folder without installing. It works on Ubuntu
  22.04, Debian 12, Fedora 36 or anything newer.
- **Steam Deck.** Install it from Desktop Mode the same way, then right-click it in
  the application menu and choose **Add to Steam** to play from Game Mode. The README
  has a short guide to the controls and screen size.
- **Homebrew overrides roll what they say.** A Check, Resistance or Effect DC typed
  into a power's override (for example "12 vs. Defense") now rolls that number,
  instead of showing it and rolling the effect's rank. A Resistance picked from the
  dropdown now stays in step when the power's rank changes.

**Install:** on Windows, download `MM-Companion-Setup-0.8.2.exe` below and run it —
or, if you already have 0.8.1 installed, press **Update** on the launcher. On Linux,
download `MM-Companion-0.8.2-linux-x86_64.tar.gz`, extract it and run `./install.sh`.

**Full changelog:** https://github.com/Mrzillka/MM-Companion/compare/v0.8.1...v0.8.2
