A hotfix for 0.9.2, which could crash on startup for anyone using a custom theme.

## Changes

- Fixed a crash on startup ("No metrics token named 'space.indent'") for anyone who had
  saved their own theme in Settings before 0.9.2. A custom theme that is missing a
  newer setting now borrows the Classic theme's value for it rather than stopping the
  app from opening.

**Install:** on Windows, download `MM-Companion-Setup-0.9.3.exe` below and run it; on
Linux, download `MM-Companion-0.9.3-linux-x86_64.tar.gz`, extract it and run `./install.sh`.

**Full changelog:** https://github.com/Mrzillka/MM-Companion/compare/v0.9.2...v0.9.3
