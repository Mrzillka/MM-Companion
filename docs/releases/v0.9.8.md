This update makes combat actions easier to follow, with clearer results in shared history and fewer roll windows. It also includes a broader set of reliability fixes across character files, online sessions and app updates.

## Changes

- Shared history clearly reports hits, misses, resistance results, calculation breakdowns and natural 1s and 20s.
- Action requests and follow-up rolls stay in history: load the check, then click the die. Actions that need no roll apply immediately.
- Corrected Block, Feint, Aid, Trick and opposed-check handling, with reminders for limits the table tracks.
- Choose the movement mode used for Slam and speed-based Stand checks.
- Resolve smashed objects and optional Trip throws directly from history, with editable object Toughness, mass and falling protection.
- Improved saved-character loading, session reconnections, mods, update cancellation and restarts.
- Further Grab and Escape improvements remain planned.

**Install:** on Windows, download `MM-Companion-Setup-0.9.8.exe` below and run it; on
Linux, download `MM-Companion-0.9.8-linux-x86_64.tar.gz`, extract it and run `./install.sh`.
